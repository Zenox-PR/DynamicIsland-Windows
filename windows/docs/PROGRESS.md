# État du projet public

Instantané initial du code natif et du site. Le développement local antérieur n'est pas réécrit ni publié avec ses conversations et diagnostics privés.

P1–P4 : validation globale documentée ; concentration et socle flottant ont reçu des essais physiques. P5 : lanceur implémenté, tests automatisés réussis, essais physiques détaillés attendus. P6 : sondes et calculs CPU/RAM/batterie, sans page active. Presse-papiers, intégrations et distribution : non livrés.

67 tests Rust rapportés sur le socle courant ; 6 tests Node et 28 contrôles navigateur pour le site. Les rapports techniques historiques restent associés à leurs binaires. Résultat brut P4 de 32/33 conservé ; pas de certification multi-écrans, DPI dynamique, endurance, jeux exclusifs ou UI Automation.
