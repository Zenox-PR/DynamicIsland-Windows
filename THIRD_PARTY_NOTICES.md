# Dépendances tierces

La licence PolyForm Noncommercial de ce dépôt concerne uniquement le code et les éléments originaux du projet. Elle ne remplace pas les licences des dépendances.

Les dépendances Rust sont verrouillées dans `windows/Cargo.lock`, et les dépendances web dans `site/package-lock.json`. Les sources tierces et leurs notices sont fournies par les registres Cargo/npm lors de l'installation ; elles ne sont pas vendues ou re-licenciées sous PolyForm par ce dépôt.

Les avis de licence et de copyright accompagnant les dépendances doivent être conservés lors de toute redistribution qui les inclut. Aucun binaire ni bundle de dépendances n'est livré dans ce dépôt de sources. Vérifier et accompagner les licences de toutes les dépendances avant une distribution binaire.

Le texte de PolyForm Noncommercial 1.0.0 est reproduit sans modification depuis le dépôt officiel PolyForm Project. Aucun code tiers Nusa, L4 ou WindyLand n'a été copié selon la documentation du projet.
